# HAR Analyzer

Плагин Dify для анализа HTTP Archive (HAR) файлов — сетевых трассировок, которые экспортируются из DevTools браузера. Передайте `.har` файл и получите структурированный отчёт о производительности и ошибках: метрики таймингов, вес ресурсов, сбойные запросы и подозрительные ответы — готовые данные для LLM-рекомендаций по оптимизации.

Исходный код: https://github.com/neyara11/dify-plugin-har_analyzer

## Что анализируется

HAR-файл фиксирует все HTTP-запросы страницы: URL, заголовки, тайминги, коды ответов и тела ответов. Плагин разбирает трассировку и формирует:

**Метрики производительности**
- TTFB (время до первого байта) и приближённая FCP (first contentful paint)
- Общее время загрузки и число загруженных ресурсов
- Разбивка таймингов по запросам (DNS, connect, SSL, send, wait, receive)

**Разбивка ресурсов по типам**
- HTML, CSS, JavaScript, изображения, аудио, видео, JSON, прочее
- Размер и время загрузки по каждому типу (корректно учитывается сжатие)

**Ошибки и диагностика**
- HTTP-ответы 4xx/5xx
- Прерванные, заблокированные запросы и сбои CORS (status 0)
- Прикладные ошибки за HTTP 200/3xx — JSON с полями `error`/`exception`/`success: false` и текстовые тела со stack trace или «Internal Server Error»
- Для каждой ошибки: заголовки запроса/ответа и превью тела ответа

**Предупреждения и наблюдения**
- Дубликаты запросов (один и тот же URL запрашивается повторно)
- Топ доменов по числу запросов
- Самые медленные запросы
- Статус кэширования и сжатия по каждому запросу (`Cache-Control`, `ETag`, `Last-Modified`, `Content-Encoding`, 304/из кэша)
- Браузер, версия, hostname и User-Agent зафиксированной сессии

## Как это работает

1. Запишите сессию: откройте DevTools браузера → вкладка **Network** → воспроизведите проблему → **Export HAR** (Chrome/Edge: стрелка загрузки; Firefox: «Save All As HAR»).
2. В Dify вызовите инструмент **Analyze HAR File** и загрузите `.har` файл.
3. Выберите формат вывода и передайте результат LLM-ноде для анализа или используйте напрямую в workflow.

Весь разбор выполняется внутри вашего деплоя Dify. Подробности обработки данных — в [PRIVACY.md](../PRIVACY.md).

## Параметры

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `har_file` | file | Да | `.har` файл, экспортированный из DevTools браузера |
| `output_format` | select | Нет | `summary` (по умолчанию), `json` или `errors_only` |

## Форматы вывода

### `summary` — человекочитаемый отчёт

Отчёт с секциями: браузер и окружение, сводная статистика (запросы, размер, домены, ошибки, предупреждения, дубликаты), метрики производительности (TTFB, FCP, общее время, число ресурсов), коды ответов, разбивка ресурсов по типам, топ доменов, дубликаты, ошибки с деталями и топ-15 медленнейших запросов.

### `json` — полные структурированные данные для workflow

```json
{
  "summary": {"total_requests": 45, "total_size_bytes": 1572864, "errors_count": 2},
  "performance": {"ttfb": 120, "fcp": 250, "total_time": 1500},
  "status_codes": {"200": 42, "404": 2, "0": 1},
  "resource_types": {"html": {}, "css": {}, "javascript": {}, "images": {}},
  "errors": [],
  "warnings": [],
  "top_slowest": []
}
```

Очень большие результаты обрезаются с пометкой (порог 50 КБ); для полной картины используйте `summary`.

### `errors_only` — быстрая диагностика

Только ошибки, предупреждения и дубликаты — с полными заголовками запроса/ответа и превью тела ответа. Удобно для разбора сбойных запросов.

## Пример workflow

```
1. Пользователь загружает .har файл из DevTools
2. Tool: HAR Analyzer (output_format: json)
3. LLM-нода интерпретирует метрики и список ошибок
4. Ответ с приоритизированными рекомендациями по оптимизации
```

Типовые сценарии: аудит производительности сайта, сравнение регрессий после релиза, диагностика медленных или сбойных API-записей, передача сетевых данных в разбор инцидента.

## Установка

**Из Marketplace** (после публикации): найдите «HAR Analyzer» в Dify → Плагины → Marketplace и нажмите **Установить**.

**Ручная загрузка**: Dify → **Настройки → Плагины → Установить плагин → Загрузить**, затем выберите `har_analyzer-<version>.difypkg` из [релизов](https://github.com/neyara11/dify-plugin-har_analyzer) исходного репозитория.

API-ключи, учётные данные и внешние сервисы не требуются.
